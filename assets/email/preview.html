Roundcube: where to paste

  1. Webmail → Settings → Identities → choose your address.
  2. In Signature, switch the editor to HTML.
  3. Either paste with Ctrl+V after “Copy signature”, or open Source code <> and paste after “Copy HTML code”.
  4. Click on “Your Name” and type your own name, then Save.
  5. In Settings → Preferences → Composing Messages, set “Compose HTML messages” to always.
